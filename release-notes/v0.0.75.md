# Fabrik v0.0.75

## Summary

Fabrik v0.0.75 makes the **`base:<branch>` two-branch-trunk workflow work end-to-end** and adds **automatic board hygiene**.

- **`base:<branch>` repos are fixed.** When an issue targets a non-default base branch, GitHub leaves the PR↔issue linkage and review data structurally empty — which previously made every such issue falsely pause at the end of Implement and never clear its review gate. Fabrik now verifies linkage directly from the PR body, feeds the review gate from base-branch-independent data, and no longer thrashes its cache re-deriving the link each poll. If you run a two-branch trunk (e.g. a `develop` → `main` model), issues now flow through the pipeline exactly like default-branch ones. Reported by the community as #1046.
- **Done items now auto-archive.** Items that have sat in Done for a week are automatically archived off the project board, keeping the board — and your GraphQL rate-limit budget — from bloating as work accumulates. This is **on by default** with a one-week grace period; tune it with `FABRIK_ARCHIVE_AFTER` or turn it off with `FABRIK_ARCHIVE_DONE=off`.

This release also folds in a broad internal code-health pass — splitting oversized files, decomposing large functions, and removing dead code — to keep the engine maintainable as it grows. No configuration changes are required to upgrade.

## Fixes
- `base:<branch>` repos: verify PR↔issue linkage from the PR body on non-default base branches, so issues no longer falsely pause at the end of Implement (#1046, #1047)
- `base:<branch>` repos: feed the review gate from base-independent REST data so it clears naturally instead of degrading to the timeout/pause path (#1050)
- `base:<branch>` repos: suppress false linkage-drift cache invalidation, eliminating per-poll deep-fetch thrash and slow close-on-merge (#1056)
- Correct cache-key and webhook-echo handling when mirroring pause labels, so paused state stays consistent across cache and board

## Features
- **Done-item auto-archive** (ADR-068): a Done item is archived off the board `FABRIK_ARCHIVE_AFTER` after its work visibly lands (default `168h` / one week; `FABRIK_ARCHIVE_DONE=on` by default, set `off` to disable). Anchored to a GitHub-side timestamp so completed work can never "vanish instantly" (#1035)

## Improvements
- Codebase-health pass: split god-files (`poll.go`, `store.go`), decompose large `engine`/`github` functions into named helpers, and remove dead code — no behavior change (#1024–#1044)

## Internal
- Test-suite splits mirroring the source refactor; assorted error-wrapping, doc, and site-copy updates.

## Upgrading

```bash
# Auto-upgrade from a running Fabrik instance
# Fabrik checks for new releases each poll cycle and upgrades automatically with --auto-upgrade

# Or download directly (auto-detects OS and architecture)
gh release download --repo handarbeit/fabrik \
  --pattern "fabrik_*_$(uname -s | tr A-Z a-z)_$(uname -m | sed 's/x86_64/amd64/' | sed 's/aarch64/arm64/').tar.gz" \
  -O - | tar xz
```
