# Fabrik v0.0.87

## Summary

**The `fabrik` plugin's MCP tools work with no configuration** (#2322). `fabrik mcp` now
finds its subscriber name on its own, so the overseer actions (`fabrik_promote`,
`fabrik_set_autonomy`, `fabrik_advance` and the rest) no longer refuse in a fresh install.
The plugin also stops overriding a per-session name, so several Claude Code sessions can
each attach to the daemon under their own name.

## Upgrading

- **The plugin's "Subscriber name" setting is gone** (#2322). If you set it, export
  `FABRIK_SUBSCRIBER` in the session's environment instead (shell profile, direnv or inline)
  to keep receiving pushed channel events. A value stored for the old setting is ignored.
- **The default name does not receive pushes.** With nothing set, the name is your OS
  username: it signs the overseer actions' audit comments and is `fabrik_subscribe`'s
  default, but it never starts the push stream. Nothing Claude Code sends when the server
  starts says whether the session can receive pushes, and a stream under a name every
  session shares would let a `claude -p` script take over your interactive session's
  stream. Set `FABRIK_SUBSCRIBER` (or pass `--subscriber`) to receive pushed events.
- If you register `fabrik mcp` yourself with `--subscriber` instead of using the plugin,
  disable the plugin's copy. The channel source then reads `server:fabrik` rather than
  `plugin:fabrik@fabrik`.

```bash
# Auto-upgrade from a running Fabrik instance
# Fabrik checks for new releases each poll cycle and upgrades automatically with --auto-upgrade

# Or download directly (auto-detects OS and architecture)
gh release download --repo handarbeit/fabrik \
  --pattern "fabrik_*_$(uname -s | tr A-Z a-z)_$(uname -m | sed 's/x86_64/amd64/' | sed 's/aarch64/arm64/').tar.gz" \
  -O - | tar xz
```

## MCP and the `fabrik` plugin

- **Subscriber name resolution** (#2322). `fabrik mcp` takes the first of: `--subscriber`,
  `FABRIK_SUBSCRIBER`, `CLAUDE_TOPIC` (exported by the `topic` session launcher), then the
  OS username (`$USER`, else the system user database). A blank value or an unexpanded
  `${...}` placeholder counts as unset at every step. The plugin's `.mcp.json` no longer
  sets `FABRIK_SUBSCRIBER`, and its `userConfig` no longer has `subscriber`.
- A session whose default-named stream is taken over by another session is told how to give
  each session its own name. `fabrik_subscribe` and a pushed `fabrik_situation` say plainly
  when the name is the default and events are held rather than delivered.
- Every action tool's description now states where its subscriber name comes from. See
  ADR 2322, which amends ADRs 2141, 1966-b and 1966-c.
