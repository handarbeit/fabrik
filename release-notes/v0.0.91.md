# Fabrik v0.0.91

## Summary

**Review gates that read the reviewer, not the clock.** The authoritative review gate now
judges each reviewer at the PR's current head. A declared bot's clean review at that head
withdraws its own earlier change request, and a verdict on an older commit reads as
"awaiting re-review". Every way out of a `wait_for_reviews` stage asks that same verdict.
A clean Pruefer review (now carrying a machine-readable findings count) starts no worker,
and the review-wait timeout restarts when a push asks for a new review, so it no longer
counts the fix loop.

**Pauses that say why, and clean stops that resume themselves.** Every engine pause now
carries a `fabrik:pause:<cause>` label (question, review timeout, CI timeout, cycle limit,
daemon stop and more). Items paused by a clean daemon stop are resumed on the next start,
and their sessions continue.

**Fewer stalls.** Stage advances no longer wait for a periodic re-evaluation, a failed
live read retries within one poll, and engine rebases that only shift diff context are no
longer mistaken for diverged branches. Optional reserved worker slots for review, CI-fix
and rebase rounds are available (`fix_round_slots`, off by default).

## Features
- Pause cause labels: every engine pause adds exactly one `fabrik:pause:<cause>`, surfaced as `pause_cause` in `fabrik_status` and channel events (#2487)
- Items paused by a daemon clean stop are resumed on the next startup, verified from live GitHub reads; set `resume_after_clean_stop: false` to opt out (#2486)
- Optional reserved worker slots for review, CI-fix and rebase rounds (`fix_round_slots`, default 0 = off); `fabrik_health.workers` reports `fix_in_use`/`fix_max` (#2490)
- Pruefer adds a hidden findings-count marker to every review body (#2488)
- `history.json` records token counts and the effective model for each invocation (#1411)

## Fixes
- Authoritative review gate: each reviewer is judged at the PR head, and a declared bot's clean review at head supersedes its earlier `CHANGES_REQUESTED` (#2465)
- Every route out of a `wait_for_reviews` stage, including the catch-up advance, consults the same review verdict (#2491)
- A clean review from an expected reviewer starts no worker and holds no gate (#2489), including for Queued merge-train members, which were ejected repeatedly until paused (#2525)
- A bot finding that Review declined at the current head now pauses for a decision instead of waiting out a timeout for a review that cannot come (#2466)
- The review-wait timeout restarts when a new head arrives, instead of counting the whole fix loop (#2467)
- An engine rebase that only shifts diff context no longer strands the issue branch or pauses it as diverged (#2517)
- A failed live read in the feedback gate retries within one poll instead of after ten (#2498)
- A stage start failure records its retry cooldown and raises a warning when it persists (#2499)
- The next stage no longer waits for the periodic re-evaluation when the advance lands while its own worker is still in flight (#2528)
- The CI gate no longer re-adds an existing completion label, which showed as reconcile drift on every periodic re-evaluation (#2530)
- A closed paused item at Done is now cleaned up and archived (#2459)
- `fabrik upgrade` refuses to migrate the plugin while a running daemon holds the directory (#2458)
- Webhook deliveries for merge-train integration PRs are no longer attached to a train member (#2483, a known issue in v0.0.90)
- Label changes around a SIGHUP restart are applied before the exec and announced exactly once with their attribution; `fabrik_health.channel.ready` reports channel readiness (#2484, a known issue in v0.0.90)
- Route liveness waits for its hook-refresh goroutine on stop (#2480)
- GitHub App refresh-loop log lines end with a newline (#2500)

## Improvements
- New docs page for the companion tools (Pruefer and Werkbank), with Pruefer's reference on the site (#2535)

## Known issues
- A merge-train trial's CI verdict can be read up to one idle poll interval after CI finishes, which slows bisection on a quiet daemon. Landings are unaffected (#2542, planned for v0.0.92)

## Upgrading

- **Hookdeck users:** Hookdeck is deprecated and will be removed in v0.0.92. Move to
  `event_source: direct` or `event_source: tailscale` (GitHub App auth). See the User
  Guide's webhook sections.

```bash
# Auto-upgrade from a running Fabrik instance
# Fabrik checks for new releases each poll cycle and upgrades automatically with --auto-upgrade

# Or download directly (auto-detects OS and architecture)
gh release download --repo handarbeit/fabrik \
  --pattern "fabrik_*_$(uname -s | tr A-Z a-z)_$(uname -m | sed 's/x86_64/amd64/' | sed 's/aarch64/arm64/').tar.gz" \
  -O - | tar xz
```
