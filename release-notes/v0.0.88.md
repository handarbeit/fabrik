# Fabrik v0.0.88

## Summary

**Pruefer reviews through plugins, and keeps reading until it has read the whole PR.**
The default review is now an embedded plugin skill (`pruefer-review:review`, #2306).
Operators can load their own review plugins and pick one by `plugin:skill`, falling back to
the default in a way the posted review shows (#2307). A repo can supply plugins through its
standard Claude Code plugin declarations, but only behind three opt-ins that default off
(#2366). Reviews resume the same session until every staged diff entry has been read, up to
a bound (#2375). Review tools are coded within an operator ceiling, and outside authors get
a read-only review (#2308, hardened by #2370).

**Engine state fixes from the 2026-10-15 state audit** (#2341–#2347). `fabrik:paused` now
wins at every advance and landing site. Every engine merge is pinned to the head the gates
judged. The Validate completion SHA survives a restart. Three cache-write paths no longer
overwrite newer state with older data.

## Upgrading

- **Pruefer: repo-supplied review plugins are off by default** (#2366). To allow them,
  set the operator's `repo_plugins`. The repo must also name each plugin in its base-ref
  `.pruefer/config.yaml` `plugins:` key, and the PR must target the default branch.
  A plugin from another repository needs a `repo_plugin_marketplaces` allowlist entry and
  a pinned commit. **Trust model:** a plugin's hooks and MCP servers run as the daemon's OS
  user.
- **Pruefer: `review_tools`** (#2308, #2370) is validated at startup. A rule that names a
  test runner, interpreter, launcher, or an exec-, write- or network-capable tool is
  refused and Pruefer will not start. Remove the rule, or narrow it to a read-only command.
- **Pruefer: review sessions no longer live in the Claude profile** (#2363). Transcripts
  are written to `.pruefer/transcripts/` and kept 7 days.
- **Pruefer: `max_coverage_passes`** (default 2, `0` disables) bounds the new coverage
  loop (#2375). Each extra pass is another resumed invocation against your Claude quota.

```bash
# Auto-upgrade from a running Fabrik instance
# Fabrik checks for new releases each poll cycle and upgrades automatically with --auto-upgrade

# Or download directly (auto-detects OS and architecture)
gh release download --repo handarbeit/fabrik \
  --pattern "fabrik_*_$(uname -s | tr A-Z a-z)_$(uname -m | sed 's/x86_64/amd64/' | sed 's/aarch64/arm64/').tar.gz" \
  -O - | tar xz
```

## Engine

- **The pause guard** (#2341, ADR 2341). Every automatic advance or landing decision on
  the stage path and in the merge train refuses a `fabrik:paused` item, and refuses one
  whose labels cannot be read. A paused merge-train member keeps the whole landing Queued
  and counts nothing against the train.
- **Merges are pinned to the judged head** (#2342, ADR 2342). These are all pinned to the
  head the CI and review gates cleared:
  - the merge-queue enqueue
  - the auto-merge enable
  - the direct-merge fallback
  - the merge train's landing

  A head that moved in between defers the landing silently. Only the head Validate
  verified can land.
- **Validate completion SHA rebuilt after a restart** (#2343, ADR 2343). It is recovered
  from the engine's own Validate comment, so a push after a restart still invalidates
  Validate. If it cannot be recovered, Validate re-runs and the item is never landed
  unverified.
- **Comment-review issue body writes reach the cache** (#2346). A poll-only daemon no
  longer feeds the next stage the pre-edit spec.
- **Deep-fetch apply writes only deep-owned facts** (#2344, ADR 2344). It no longer writes
  the poll-start snapshot over newer state, and the cache-hit copy keeps the merge-queue
  fields.
- **`projects_v2_item` webhooks filtered by project and Status field** (#2345, ADR 2345).
  Events for other boards, or for edits to fields other than Status, are ignored. Without
  the filter they were triggering fetches and could be matched as echoes of the engine's
  own writes. **Not exercised live in this release:** the gate beds have no webhooks
  configured, so this path is covered only by unit tests and recorded payload fixtures.
  Verification with a real delivery follows the release.
- **Layer 1 status refresh is applied as a GitHub read** (#2347, ADR 2347), not as an
  engine write. It no longer creates engine-write protection, or engine attribution, for
  a value it only read.

## Pruefer

- **Embedded review skill** (#2306, ADR 2306). The plugin is written to a fresh temp
  directory for each review and is the only `--plugin-dir` passed. The `Skill` grant is
  scoped to the run's own reference. A review whose skill errors, or is never invoked,
  posts nothing.
- **Operator plugins and `review_skill`** (#2307, ADR 2307). The base branch is pinned to
  one SHA per review, and config and guidance are read at it. The fallback to the default
  skill is posted as a `Review skill fallback` notice.
- **Repo plugins from standard declarations** (#2366, ADR 2366). These are
  `.claude-plugin/marketplace.json` and `.claude/settings.json`
  `extraKnownMarketplaces`, read at the base SHA:
  - The tree's size and paths are checked from its listing before any file is read.
  - Plugins are cached by tree SHA, within a byte cap.
  - Skipped plugins are named in the fallback notice.
- **Coded review tools; outside authors read-only** (#2308, ADR 2308). Trust is decided
  from the author's association with the repo, with Dependabot excepted. Hardening (#2370):
  - tool names are compared case-insensitively;
  - a wider denylist of side-effect-capable tools;
  - every granted rule is checked again before each run.
- **Coverage resume loop** (#2375, ADR 2375). Pruefer only resumes when the first pass
  produced a complete review and left staged entries unread. The posted review's coverage
  block is the union of every accepted pass's coverage.
- **Staged-entry batch limit** (#2362, ADR 2362). The reviewer reads diff entries one at a
  time, or in batches of at most 20 KiB, below the size at which the Claude CLI cuts a
  result to a 2 KB preview. Entries seen only as a preview are counted as unread.
- **Head SHA fallback** (#2331). When `refs/pull/<N>/head` is missing, Pruefer fetches the
  head commit by its SHA.
- **Review sessions moved** (#2363, ADR 2363) to `.pruefer/transcripts/`, kept 7 days.
